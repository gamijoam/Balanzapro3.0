# BalanzaPro3.0
Blueprint de ERP comercial modular, local-first respecto a Internet (no escrituras autónomas sin autoridad en V1), para Venezuela y expansión internacional. Estado: planificación aprobada parcialmente; sin código de aplicación ni certificación fiscal.
## Comenzar
1. Leer AGENTS.md, docs/MASTER.md, docs/decisions/README.md y TECH_STACK.md.
2. Leer ROADMAP.md y BACKLOG.md; ejecutar únicamente una tarea autorizada.
3. Ratificar ADR pendientes que afecten esa tarea y registrar alternativas.
4. Utilizar PROMPT_INICIAL.md en Codex; validar con TDD y revisión.
Las carpetas de código son marcadores, no una aplicación operativa. No desplegar en producción. Sin remoto Git configurado. El PDF maestro es una vista de la documentación; los Markdown y ADR versionados prevalecen.
