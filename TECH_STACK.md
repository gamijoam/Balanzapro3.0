## Nativas y decisiones de infraestructura
PostgreSQL: ACID, row locks, constraints, partial indexes, NUMERIC, JSONB para atributos no críticos, pg_trgm, vistas/materializadas, funciones/triggers si aportan valor documentado, RLS como defensa adicional evaluada, NOTIFY solo señal, pg_dump/pg_restore/basebackup/WAL/PITR. SQLite FTS5 y representación exacta. Go crypto/ed25519, encoding/csv, pprof, testing, race/fuzz; Flutter Shortcuts/Actions. Evitar por ahora Kubernetes, microservicios, Kafka, Redis obligatorio, Electron/Tauri, PostgreSQL por caja, event sourcing general y sincronización bidireccional indiscriminada. Usar outbox transaccional. No duplicar ORM/generadores. Evaluar versiones, CVE, licencias, plataforma, consumo RAM/CPU, compatibilidad offline y alternativa.
