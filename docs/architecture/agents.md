# Coordinación de agentes
Coordinador/arquitecto: divide backlog por contratos y dependencias, evita colisiones, aprueba interfaces y propone ADR. Go: dominio y puertos. PostgreSQL: migraciones, locks, planes de consulta, consistencia. Flutter: presentación, accesibilidad, caché. UX: tokens, prototipos y flujos. Experto comercial: invariantes y casos. Seguridad: threat model y permisos. QA: pruebas RED y revisión independiente. DevOps: entornos, distribución, respaldos, SBOM. Auditor: revisa evidencia y no implementa cambios sin autorización. Cada rol puede ser una sesión de IA; no se asume orquestación instalada. Una rama/worktree por tarea, contratos coordinados, PR con revisión humana. No dar acceso de escritura a PROD. Skills en .agents/skills son instrucciones, no plugins instalados ni agentes ejecutándose.
