# ADR-005 — Autoridad local de inventario

**Estado:** APROBADA

## Decisión o propuesta
Un escritor por stock; cliente sin acceso directo a PG.

**Procedencia:** reconstrucción del contexto inicial disponible, no transcripción literal.

**Ratificación:** ratificada expresamente por el propietario del proyecto el 2026-11-26 (BP-001), con el texto vigente sin cambios. Respaldo: a la pregunta "¿Ratificas ADR-005, ADR-006 y ADR-016?" el propietario respondió "Ratificar tal cual".
