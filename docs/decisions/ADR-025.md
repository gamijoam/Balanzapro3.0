# ADR-025 — Autorización de supervisor

**Estado:** APROBADA (2026-11-26)

## Respaldo del propietario
2026-11-26, Issue #16. A la pregunta "ADR-025: … ¿Con qué credencial se autoriza?", con el modelo descrito abajo, el propietario respondió **"PIN personal del supervisor"**.

## Decisión
1. Cuando un usuario necesita hacer algo fuera de su permiso o límite (ADR-024), como un descuento mayor o una anulación, un supervisor puede autorizar **esa acción concreta**.
2. **Credencial:** el **PIN personal del supervisor** (ADR-026), que verifica el servidor con límite de intentos y bloqueo temporal. **Nunca hay PIN compartido.**
3. La autorización:
   - queda **ligada** al tipo de acción, a la entidad y al monto o límite pedidos, a la terminal y a la sesión que la solicitó;
   - es de **un solo uso** y **expira** en unos 2 minutos (valor inicial, configurable dentro de límites seguros según ADR-027);
   - la valida el servidor contra los permisos y límites **del supervisor** en ese ámbito. Si el supervisor tampoco puede, se deniega.
4. **Auditoría:** se registran el solicitante, el supervisor, la acción, la entidad, el monto, la terminal, el resultado, la hora y la correlación, sin guardar el PIN.

## Consecuencias
- Prueba de aceptación SEC-02: reutilizar una autorización, usarla para otra acción o monto, en otra terminal o después de vencer, se deniega. También se deniega si el supervisor no tiene el permiso o el límite.
- Se implementa en BP-009, tras las credenciales de BP-008, dividida en PRs según AGENTS.md.
- Una sustitución requiere una nueva ADR.
