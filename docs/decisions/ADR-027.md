# ADR-027 — Configuración tipada por ámbito

**Estado:** APROBADA (2026-11-26)

## Respaldo del propietario
2026-11-26, Issue #18. A la pregunta "ADR-027 (configuración): ¿ratificas este modelo?…", con el modelo descrito abajo, el propietario respondió **"Ratificar tal cual"**.

## Decisión
1. **Claves tipadas declaradas por cada módulo** en su manifiesto (ADR-023). Cada clave define su tipo, su valor por defecto, su validación y los **niveles** en que se puede fijar.
2. **Niveles:** global > organización > empresa > sucursal > terminal > usuario. **Gana el nivel más específico permitido** para esa clave.
3. **Seguridad y fiscal no se pueden anular:** esas claves solo se fijan en niveles administrativos (global, organización o empresa) y nunca por preferencia de terminal o usuario.
4. **Versionada:** cada cambio crea una versión nueva con actor, fecha y motivo. El historial no se edita, y las operaciones guardan la versión que aplicaron cuando importa para reconstruirlas.
5. Cambiar la configuración exige permiso (ADR-024) en el ámbito correspondiente.

## Consecuencias
- Pruebas de aceptación:
  - resolución por nivel más específico;
  - rechazo de valores con el tipo o la validación incorrectos;
  - rechazo de una clave de seguridad o fiscal en el nivel de terminal o usuario;
  - el historial de versiones es inmutable;
  - la configuración de una empresa no afecta a otra (SEC-01).
- Se implementa en BP-009, dividida en PRs según AGENTS.md.
- Una sustitución requiere una nueva ADR.
