# ADR-075 — Orden/recepción/factura/pago

**Estado:** APROBADA

## Decisión o propuesta
Separar logística, obligación y dinero.

## Consecuencias
Aplicar al dominio correspondiente, con las reglas y pruebas de docs/. Una sustitución requiere una nueva ADR; no cambiar retrospectivamente el registro. La aprobación no implica implementación ni certificación.
