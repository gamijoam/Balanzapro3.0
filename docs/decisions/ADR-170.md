## Diferidos (con motivo)
- **sqlc**: el núcleo usa pocas consultas, casi todas condicionales y con casts NUMERIC→text; se escriben a mano con pgx. Reevaluar cuando crezca el número de consultas (ADR-009 sigue pendiente).
- **testcontainers-go**: el entorno de desarrollo actual no tiene daemon Docker. Las pruebas de integración usan `BP_TEST_DATABASE_URL` (PostgreSQL desechable) y CI usa un servicio PostgreSQL 16; `BP_REQUIRE_DB=1` convierte la ausencia de BD en fallo, no en omisión.
- **Task**: no instalado; se usa `make` (sin dependencia nueva).
