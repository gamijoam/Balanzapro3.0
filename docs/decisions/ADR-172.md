# ADR-172 — Desviaciones y añadidos de dependencias no aprobados explícitamente

**Estado:** APROBADA (2026-11-26)

## Respaldo del propietario
2026-11-26, revisión correctiva del PR #1. A la pregunta "ADR-172 agrupa decisiones que no aprobaste explícitamente: google/uuid, diferir sqlc y testcontainers, make en lugar de Task y govulncheck v1.9.0. ¿Las ratificas?", el propietario eligió **"Ratificar todas"**. sqlc y testcontainers se reevalúan cuando haya más consultas o Docker disponible.

## Contexto
La revisión correctiva del PR #1 comprobó que la ADR-170 se había marcado como APROBADA con decisiones que el propietario no eligió. Se separan aquí para que se ratifiquen o se reviertan.
