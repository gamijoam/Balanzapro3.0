# Instalación, licencias, actualizaciones y soporte (142–168)
Control plane privado separado, opcional para operar localmente. Individual Windows: Flutter/Go/PG/SQLite/servicio respaldos/device agent; servidor LAN: Go/PG/servicios; terminal: Flutter/SQLite/adaptadores; nube HTTPS. Instalador Inno Setup candidato, preflight puertos, capacidad, servicios, credenciales únicas, no Docker Desktop obligatorio. Linux systemd o Compose, iOS requiere macOS/Xcode y distribución permitida; Android por Play/empresa, Windows firmado. Web LAN debe probar HTTPS, almacenamiento y periféricos; no asumir paridad. mDNS opcional, código de un uso con expiración, aprobación, autenticación y fallback manual. No abrir PostgreSQL al público.
Licencias offline Ed25519: payload canónico y firmado con license_id, installation_id, plan, entitlements, límites de terminal/sucursal/módulos, vigencia, gracia; clave privada solo emisor protegido y rotación. Verificar en servidor, clave pública cliente, renovación online/archivo. No revocación inmediata offline ni invulnerabilidad al reloj/manipulación. Gracia 30 días orientativa; aviso antes, restricción de operaciones nuevas según contrato, no cortar operación en curso, conservar lectura/exportación/respaldo y obligaciones fiscales. Precios/planes aún no definidos.
Actualizador: descargar firmado/hashes y metadatos, verificar compatibilidad/expiración y evitar downgrade no autorizado (TUF candidato); descarga no interrumpe; mantenimiento, respaldo, migración, healthcheck, confirmar o recuperar. Canales dev/alpha/beta/piloto/estable/LTS. API versiones compatibles, migración expand-contract, SQLite por terminal, conservar borradores; rollback no equivale a reinstalar binario si esquema cambió. No publicar automáticamente por un PR. Tiendas móviles siguen reglas propias.
Respaldos 3-2-1, cifrados, externos y preferible inmutables/desconectados; pg_dump/restore para lógico y basebackup/WAL/PITR según perfil; Restic para almacenar archivos consistentes, no copiar PG activo indiscriminadamente. Incluir documentos/archivos/configuración y datos locales no sincronizados; credenciales separadas; verificar restauración aislada y manifest/checksum. RPO/RTO propuestos pequeño 6h/2h, minimarket 1h/1h, grande 5–15min/15–60min; validar hardware, red, tamaño, disponibilidad de repuesto. Respaldos desde primera persistencia.
Diagnóstico: health/readiness, versión, red, disco, memoria, terminales, colas, periféricos, respaldo y correlación. Exportar bundle depurado sin datos sensibles por defecto. Agente inicia TLS saliente; comandos allowlist, identidad, autorización por operación, auditoría, expiración y consentimiento para escritorio/acceso comercial. RustDesk/VPN candidatos. Sin puerta trasera. Logs rotativos slog, OpenTelemetry opcional, Prometheus/Grafana central, Uptime Kuma, Sentry/GlitchTip candidatos, pprof restringido. No instalar una gran pila en una bodega.
