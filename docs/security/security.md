# Seguridad y permisos
RBAC + ámbito + atributos y límites; Casbin candidato. Deny-by-default y autorización en cada comando/consulta. Prohibido confiar en UI. Usuarios/terminales con credenciales individuales, sesiones revocables, TLS, Argon2id para claves, almacenamiento seguro, rate limits; TOTP/passkeys opcionales. Supervisor con PIN propio, reautenticación, autorización de una acción y monto, expira y no se reutiliza. Sin PIN compartido. Roles iniciales vendedor/cajero/almacenista/comprador/tesorero/supervisor/propietario; permisos personalizables. Aislar datos por empresa/sucursal; pruebas de IDOR y escalada. Doble aprobación financiera opcional. Auditoría actor, acción, entidad, ámbito, antes/después depurado, motivo, hora y correlación; acceso restringido, no registrar secretos. Revocación offline solo al contacto o expiración. Control plane no tiene acceso a ventas por defecto; consentimiento explícito para diagnóstico sensible y escritorio; conexiones salientes, comandos allowlist, tiempo limitado y auditado. Claves privadas de licencias y releases nunca en clientes. Threat model pendiente: robo de terminal, manipulación de reloj, replay, red LAN hostil, ransomware, dependencia comprometida, restauración maliciosa. No prometer invulnerabilidad.
